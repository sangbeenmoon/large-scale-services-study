## 핵심 내용 요약
### mysql 분산 처리
- mysql 의 read 분산
  - primary - secondary replication
- mysql 의 write 분산
  - mysql 대신 key-value store 사용 / scale up 등을 우선적으로 고려.
  - primary 다중화는 최후의 수단. 
    - 단점 : join 사용 제한 / 운영 복잡도 증가.

### 용도특화형 인덱싱
- RDBMS 의 한계
  - e.g. 대규모 데이터의 전문 검색 , 유사문서 탐색, 데이터마이닝, ...
  - 해결 : RDB 로부터 데이터를 주기적으로 추출해서 index 서버를 구성하고, index 를 메모리에 올려둔다. 그리고 index 서버에 api 를 호출해서 필요한 정보를 조회한다.

### 압축
- 효과 : 용량이 적어지면 디스크 I/O 를 줄일 수 있음 -> 처리 속도 향상.
- 압축의 기초 : 기호의 확률분포를 바탕으로 자주 나타나는 기호에는 짧은 부호를, 그렇지 않은 기호에는 긴 부호를 부여한다.
