## 핵심 내용 요약
- 대규모 서비스에서는 부하를 어떻게 분산하고, scalability를 확보하는가가 중요하다. 
   - 이것이 간단하지 않은 이유는..
      - 1. 데이터가 많아지면 메모리내에서 계산할수 없어서 -> 메모리는 디스크보다 10^5~10^6이상 빠르다. (탐색 속도 + 전송 속도)
      - 2. AP서버의 경우(cpu i/o) scale out 하면 된다. IO 부하인 DB서버의 경우 쓰기를 분산하고/data consistency 측면에서 더욱더 고려할게 많다.
   - 고려해야할 사항
      - "어떻게 하면 메모리에서 처리를 마칠수 있을까?"
      - 데이터량 증가에 강한 알고리즘 사용 e.g. 선형 탐색 -> log order
      - 데이터 압축/검색알고리즘 사용.
