## 핵심 내용 요약
- 요구사항 : 사용자가 북마크한 게시글 중에서 키워드 검색.
  - 아이디어 : 검색 시스템을 별도로 만들어서 사용자가 북마크를 추가하는 타이밍에 맞춰 사용자별로 검색 인덱스를 준비해두고 갱신. 검색할 때는 사용자의 인덱스 내에서만 검색.
- 검색 아키텍처
  - grep 형 : 풀스캔. O(m+n) (KMP) ~ O(mn) / 장점 : 즉시성, 검색 누락 없음 , 병렬성.
  - suffix 형 : 검색 대상 전문을 구조화해서 전부 메모리에 들고 있음. e.g. Trie
  - 역인덱스 형 : 검색하기 전에 인덱스를 전처리로 만들어 둠.
- 역인덱스 = dictionary (term) + postings
